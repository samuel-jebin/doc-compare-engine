# Document Comparison Engine 📝

This is a Flask-based web application to:
- Upload PDF/doc files
- Extract content via Azure Document Intelligence
- Convert to HTML radio forms
- Preprocess and extract clean text
- Compare with source-of-truth JSON from Azure Blob
- Return exact-word-level mismatches

## Tech Stack:
- Python (Flask)
- Azure Document Intelligence
- Azure Blob Storage
- BeautifulSoup
- OpenAI / GPT comparison engine
